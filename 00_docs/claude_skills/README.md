# ISZE Claude Skills

Custom Claude / Cowork skills for the ISZE workspace. Install on any device via Cowork → Settings → Skills → Install from file.

| Skill file | Purpose |
|---|---|
| `data-analysis-assistant.skill` | Excel/Python, KPI analysis, GPS benchmarking, PMS gaps, UIO, AIM, Power BI |
| `isze-strategic-assistant.skill` | Position papers, distributor briefs, IML correspondence, sparring partner |
| `isze-gps-auditor.skill` | GPS data auditor — validates billing extracts before any GPS calculation |
| `productivity-assistant.skill` | Email drafting, meeting prep, task prioritisation — calibrated to Jerome's style |

## Re-installing on a new PC

1. Clone the ISZE repo
2. Open Cowork
3. For each `.skill` file: drag it onto the Cowork window, or use Settings → Skills → Install
4. The skills read reference files from the repo automatically (paths in SKILL.md)
