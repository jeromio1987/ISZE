# Delegator board

One shared page so that every agent working in this workspace can see what the last agent
changed, without any chat between them. There is no message channel between agents on this
machine — Cursor exposes no such tool — so this board is the coordination mechanism.

**Any agent working in this workspace:** read the last ~10 rows before you start, and append a
row when you finish a substantive piece of work.

| Who | Rows look like |
|---|---|
| `delegator-watch` | Written automatically by `04_tools/workspace/isze_delegator_watch.ps1` when a watched AIM file's fingerprint moves |
| Any other agent | Append a row yourself: time, who you are, what changed, files touched, next step |

Keep it to one line per event. This is a change log, not a report — put the detail in the file
you changed.
