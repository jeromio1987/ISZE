# GPS reconciliation — lessons (2026-07-03)

**Harness:** `04_tools/gps_reconcile.py` — single entry point for all GPS integrity checks
(raw SAP → billing JSON → billing-FY CSVs → v9 snapshot → dashboard HTML → PRISM SPU feed
→ Kosha workbook chain). Report: `01_data/00_derived/gps_reconciliation_report.json`,
exit non-zero on hard failure. Run after every GPS upload (RUNBOOK Step 4b).
Smoke tests: `04_tools/tests/test_gps_reconcile.py`.

## Two GPS bases — never cross-compare

| Basis | Excludes | Artifacts |
|---|---|---|
| **Kosha billing** | BillT S1/G2/RE/ZFD/S2, SaTy CR/RE, TRANSPORT (surcharge-neutralised) | `gps_billing_clean.json` + sidecars, `gps_master.csv`, Kosha v3c/v3d/toggle workbooks |
| **Full GPS-clean** | Kosha set **plus** service fees, late payment, demurrage, Shell 550047/550070, SaTy ZDR | `gps_billing_fy_*.csv`, waterfall, PRISM parquet/SPU |

Difference is real money: ITUK service fees ≈ €150K (FY24) / €202K (FY25) sit in the Kosha
basis but not the full-clean one. The old `_audit_gps_integrity.py` check "v3c == gps_clean_all_fy_v2"
mixed the two bases and perma-failed — removed 2026-07-03.

## Israel (UMI/UTI) basis trap

The dedicated `Sales_israel_1799&_1797.XLSX` extract is canonical for UMI/UTI; the main CY files
also contain payers 1797/1799 but with the pre-merge-fix split. Anything built from main files
alone (the old ad-hoc `gps_billing_fy_*_2026-07-01.csv` exports, archived to
`01_data/92_archive/gps_billing_fy_adhoc_2026-07-01/`) understates Israel FY25/26 by €0.2–0.5M.
Canonical CSVs are now regenerated by `gps_reconcile.py --rebuild`.

## Payer-map completeness is a standing risk

New SAP payer codes appear silently (2733 Grand Avto, 2734 CBC-Trans, 373 Isuzu Motors Int
Operations — €591K was sitting in UNK_* buckets of `gps_billing_clean.json` until 2026-07-03).
`gps_reconcile.py` hard-fails when unmapped payers exceed €5K/FY. Remaining known: UNK_2686 (€360 FY26).

## v9 snapshot / GPS dashboards are point-in-time

`91_build/gps_snapshot.json` (= `gps_v9_snapshot.json`) has CY2025 sales **hardcoded 12-Jun-2026**,
before the Israel refresh — raw rebuild is now 2–4.5% lower for most DBs, UMI −20%, UTI −7.5%.
The GPS dashboards embed these constants verbatim (ITUK 45.6% ex-warr = canonical v10 study figure).
Re-basing needs Jerome's decision; harness reports it as a soft WARN, not a failure.

## Ops gotchas

- Fleet copies of the GPS dashboard had a nested `<script><script src=CDN>` tag → ECharts never
  loaded, page fully blank. Fixed 2026-07-03 by inlining ECharts (self-contained rule). Canonical
  working file: `02_dashboards/gps/ISZE_GPS_Dashboard_v9.html`.
- Console prints with `−`/`·` crash under cp1252 when scripts run via subprocess — every tool
  script needs `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`.
- When absorbing a sub-audit via subprocess, verify its report file is *fresh* (mtime after start),
  or a crash silently reports last month's verdicts.
