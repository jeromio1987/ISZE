📐 Approach: Documented, Reusable Methodology

All tools developed during FY2026 follow a structured methodology — documented in Markdown specification files and configuration templates — so any colleague can understand, replicate or extend each tool independently. This was a deliberate choice: not to build black-box outputs, but to create a foundation others can build on.

📄 Specification documentation
pricing_logic_2026.md, gps_pms_framework_spec.md, sales_export_specification.md, GPS_Dashboard_Roadmap.md — each tool has a written spec explaining logic, assumptions and data sources.
🔁 Version control
Key tools maintained under git. Multiple versioned releases (e.g. UIO v1→v17, PMS analysis v1→v5) with traceable changes, so rollback and auditing are possible.
⚙️ Config templates
isze_config.TEMPLATE.json and SETUP.txt files bundled with each tool — a new user can install and run any tool independently without needing to ask the author.
🤖 AI Skill framework
Pricing logic, strategic context and data analysis rules encoded into reusable AI skills — meaning the institutional knowledge is not locked to one person but is callable by anyone with access.

🐍 Python Applications & Data Pipelines 5
Streamlit Multi-Page Dashboard App
Full Python-based web application with 10 pages across 5 modules: Sales & Pricing, ITUK, Strategy, Competitiveness, and Distributors. Includes FX Impact, Class Sensitivity, PMS Opportunity, Plan Gap, AIM Intelligence and Distributor KPIs. Shareable via Cloudflare tunnel.
Python / Streamlit Live ISZE_Dashboard/
GPS / PMS Dashboard App
Calculates Genuine Parts Supply opportunity per distributor. Ingests UIO parc data, applies PMS capture rate assumptions, and outputs revenue gap per service interval and vehicle family. Basis for the PMS joint programme with ITUK.
Python / Flask Live gps_dashboard/
EU Tender Scraper v3
Pulls and scores public procurement notices from TED (Tenders Electronic Daily), Doffin (Norway), Hilma (Finland) and UK Find-a-Tender. Applies CPV code filtering, country targeting and relevance scoring. Runs on Windows schedule via .bat file. Outputs scored Excel + HTML dashboard.
Python / Public API ✅ Legal — Public data tender_scraper_v3.py
Autodoc Competitive Price Scraper
Fetches aftermarket competitor prices from autodoc.co.uk for top-300 Isuzu PNs by CY2025 revenue. Uses Playwright browser automation with randomised delays and resume capability. Outputs CSV fed into the Competitiveness Dashboard. Eucon_pricing.xlsx contains 1,365 priced PN comparisons across 11 countries.
Python / Playwright ⚠️ ToS grey area — public prices autodoc_scraper.py
KS International Price Scraper
Companion to the Autodoc scraper — pulls IAM prices from KS International catalogue search for cross-referencing competitor pricing on the same Isuzu part numbers.
Python / Requests ⚠️ ToS grey area — public prices ks_scraper.py
