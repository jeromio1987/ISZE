🔄 Updating This Tracker With New Monthly Data

When a new monthly SAP export is available (same format as data(20).xlsx — IE40 billing data), run the Python script below. It regenerates this HTML file with updated data automatically.

  1. Export SAP billing data for the new period (BillT=F2, SOrg IE40) — same format as CY2025
  2. Save the file to your Isuzu/ folder (e.g., data_jan2026.xlsx)
  3. Open Claude Cowork and say: "Update the monthly sales tracker with [filename]"
  4. Claude will merge the new data, recalculate all metrics, and regenerate this file
  5. Copy the updated ISZE_Monthly_Sales_Tracker.html to your hosting space
