WHAT THIS DOES
--------------
Weekly scrape of public procurement portals across ISZE markets.
Keeps notices that fit Isuzu commercially: D-Max / N-Series / LCV
supply and real fleet R&M (parts pull). Scores Fit / Win / Econ,
links sized fleets to GPS addressable wallet, builds dashboards.

  Notices in the commercial net are gated (core CPV or LCV signal).
  Transport-services CPV, SEND/passenger routes, and generic car
  R&M without an LCV signal are dropped — not merely ranked lower.
  GPS € applies only to pickup/truck product-fit (not pure van/LCV).

STEP 1 — PYTHON
---------------
Python 3.10+ on PATH. Then once:

  pip install requests openpyxl beautifulsoup4 lxml


STEP 2 — RUN
------------
Double-click: run_tender_monitor.bat

It will:
  1. Scrape (TED + national feeds; 10–20+ min if Contracts Finder rate-limits)
  2. Publish live JSON under ISZE data dashboards
  3. Build v2 HTML
  4. Build v4 GPS/PMS HTML

Open the v4 dashboard:

STEP 3 — NORDICS KEYS (optional but needed for NO/FI national)
--------------------------------------------------------------
Without keys, Norway (Doffin) and Finland (HILMA) are SKIPPED loudly
(source health = AWAITING_KEY — not a dead endpoint). TED still covers
some Nordics above-threshold notices.

  1. Read: NORDICS_API_KEYS.md
  2. Copy nordics_api_keys.env.example → nordics_api_keys.env
  3. Paste Primary keys as ISZE_DOFFIN_API_KEY / ISZE_HILMA_API_KEY
  4. python verify_nordics_keys.py
  5. Never commit nordics_api_keys.env

Do NOT paste keys into tender_scraper_v3.py.


WHAT THE NUMBERS MEAN
---------------------
  Addressable GPS / year = fleet_size × (max_spend_eur / uio_units)
    → full genuine wallet per unit for that distributor year.
    → ONLY on pickup/truck product-fit when a GPS map row exists.
    → NOT expected revenue. No win rate applied.
  Capture at current rate = fleet_size × actual spend_per_unit_eur
  Contract value = published Est. Value when the notice carried one.
    Missing stays null / "—" — never forced to 0.
  GPS column empty for most rows = no fleet size and/or no SPU map
    and/or van/LCV product-fit (null ≠ 0).

TROUBLESHOOTING
---------------
Script crashes immediately → Python not on PATH.
ModuleNotFoundError → repeat pip install line.
Dashboard 0 / empty → read tender_monitor_log.txt + source banner.
UnicodeEncodeError → always run via the .bat file.
