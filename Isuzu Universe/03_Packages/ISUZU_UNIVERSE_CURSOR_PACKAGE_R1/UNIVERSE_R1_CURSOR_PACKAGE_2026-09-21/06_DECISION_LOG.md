## Status vocabulary

`accepted` means the specified scope is reviewed and supported. `partial` means explicit requirements remain open. `draft` means a proposed definition awaiting evidence/review. `blocked` means a named prerequisite prevents that activity. `not_reviewed` is not the same as missing. `deferred` is a deliberate scope decision. `prepared_not_dispatched` means a handoff file exists, not that Cursor has received or run it.
