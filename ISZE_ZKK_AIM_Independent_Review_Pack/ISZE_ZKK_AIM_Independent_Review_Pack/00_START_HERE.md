# ISZE ZKK versus AIM - independent review handover

Prepared 20 September 2026. This is the available evidence pack, not a claim that every input for a complete empirical comparison is present. Use only in an ISZE-approved environment.

## Start here

Upload this archive to the reviewing model and ask it to read `01_PROMPT_FOR_NEXT_MODEL.md` and carry out the assignment. The same prompt is supplied separately outside the archive for copying.

The user needs a judgement between ZKK and AIM, not another standalone sales report. The prompt requires a 10-line executive summary followed by the actual comparative review and recommendation. It does not prescribe the outcome.

## Evidence precedence

Use original dated source definitions and verified controls where available. Treat the earlier generated workbook as prior work to check. New handover aggregates reproduce its method and retain its provisional status. New templates and instructions are not source evidence. Do not accept previous conversational verdicts as proof.
