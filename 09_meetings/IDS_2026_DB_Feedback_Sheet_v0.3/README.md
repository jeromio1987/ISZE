# Isuzu Dealer Standards 2026 — dealer feedback sheet (v0.3)

A working document for distributors to use with their dealers after the 2026 IDS
evaluation. It turns the evaluation result into something a dealer can read in
two minutes and act on the same day.

This is a **draft for review (v0.3)** — not yet a released pack.

**What changed vs v0.1 / v0.2:** the executive summary (layer A) now carries
**Suggested next steps — edit in the meeting**: 2–3 starter actions pre-filled
from the same largest checklist gaps used for Kaizen. Owner, target date and
proof stay blank for the meeting. Kaizen on the workshop pack is unchanged.

v0.1 and v0.2 folders are **unchanged** and stay in place.

## What is in the folder

| Layer | What it is | Use it for |
|---|---|---|
| **A — Executive summary** | One printed page: score, band, vs market average, top 3 strengths, top 3 gaps, **suggested next steps** | Open the review. Hand it to the dealer principal. |
| **B — Dealer workshop pack** | Exec summary + section scorecard A–E + Kaizen action table | The working session with the dealer. |
| **C — Distributor rollup** | Network cover + dealer list | Where to spend visit time. |
| **D — Commitments** | Block the dealer fills in and returns | Follow-up. |

## How a distributor uses it

1. **Prepare.** Open the rollup (layer C).
2. **Print the one-pager.** Executive summary is designed for one A4 page. Suggested
   next steps are starters — edit them in the meeting.
3. **Run the review.** Section scorecard as conversation structure, then agree
   **3 to 5 Kaizen actions** (also pre-filled from checklist gaps). Every action
   needs an owner (role), a target date and proof.
4. **Close the loop.** Commitments sheet returns; consolidate as needed.
