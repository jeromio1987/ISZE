## Rollup blocks (layer C)

| Block | Content |
|---|---|
| **Hit list** | Up to 12 dealers below market average and/or Needs improvement, with score / pp / band / why |
| **Incomplete lane** | FR/ES: red-marked (not completed). Other markets: zeros or **None** |
| **Suggested DB next steps** | 3–5 network actions from patterns; Owner / date / proof blank |
| **Pull scorecard** | Blank monthly metrics + definitions (visited %, actions closed, incomplete cleared, escalations) |
